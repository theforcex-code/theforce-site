# THE FORCE

Site do estúdio THE FORCE (São Paulo) — arte, tecnologia e experiências imersivas.

Ao vivo: https://theforce-portfolio.vercel.app

- Next.js 14 (pages router), React, TypeScript
- three.js nas páginas Next Wave, Contact e About
- Projetos em `components/work.json`; mídias servidas por um bucket público do Cloudflare R2

```
npm install
npm run dev
```
